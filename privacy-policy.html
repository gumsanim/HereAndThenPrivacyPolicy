시행일: 2026년 6월 3일

Pinvely(이하 "서비스")는 이용자가 장소와 일상을 기록하고, 친구와 선택적으로 공유할 수 있도록 돕는 모바일 앱입니다. 서비스는 이용자의 개인정보를 중요하게 생각하며, 수집하는 정보와 이용 목적을 투명하게 안내합니다.

1. 수집하는 개인정보 항목

회원가입 및 프로필
  • Firebase 사용자 식별자(UID)
  • 이메일 주소(Google 로그인 또는 Apple 로그인 시 제공되는 이메일)
  • 닉네임, 프로필 사진, 프로필 색상
  • 친구 코드 및 친구 코드 검색을 위한 정규화된 값
  • 언어, 테마, 컬러 톤 등 앱 설정
다이어리 및 공유 기능
  • 다이어리 제목, 본문, 날짜, 장소명, 주소, 지도 좌표
  • 주제 아이콘, 기분, 날씨, 다이어리 그룹 정보
  • 첨부한 사진 및 동영상, 임시저장 데이터
  • 공유 대상 친구, 친구 그룹, 공유된 다이어리 메타데이터
  • 추억 스탬프, 읽음 여부 등 공유 다이어리 이용 기록
친구 및 알림
  • 친구 요청, 친구 관계, 친구 그룹, 친구별 표시 색상
  • 푸시 알림 전송을 위한 FCM 토큰
  • 알림 시간 계산을 위한 시간대, UTC 오프셋
  • 휴면 상태 여부 및 휴면 신청 시각

2. 개인정보 이용 목적

  • 회원 식별, 로그인, 프로필 제공
  • 지도 기반 다이어리 작성, 조회, 수정, 삭제, 임시저장
  • 친구 코드, 친구 요청, 친구 그룹, 공유 다이어리 기능 제공
  • 공유 다이어리의 읽음 표시 및 추억 스탬프 기능 제공
  • 검색, 필터링, 전체 다이어리, 공유받은 다이어리, 추억 타임라인 제공
  • 친구 요청, 다이어리 공유, 추억 스탬프, 과거의 오늘 알림 등 푸시 알림 제공
  • 테마, 언어, 컬러 톤 등 사용자 설정 유지
  • 휴면 신청, 휴면 해제, 회원 탈퇴 등 계정 관리 처리

3. 친구 공유 및 공개 범위

  • 다이어리는 기본적으로 작성자 본인에게만 보입니다.
  • 이용자가 친구 또는 친구 그룹에 공유한 다이어리만 해당 친구에게 표시됩니다.
  • 친구 관계가 끊기면 서로 공유했던 다이어리는 상대방 화면에서 보이지 않습니다. 다시 친구가 되면 기존 공유 기록이 다시 표시될 수 있습니다.
  • 휴면 신청 시 친구 목록, 공유 다이어리, 추억 스탬프 등은 상대방 화면에서 숨겨지며, 휴면 해제 시 다시 표시될 수 있습니다.

4. 보유 및 이용 기간

  • 이용자의 정보는 서비스 이용 기간 동안 보관됩니다.
  • 휴면 신청은 데이터를 삭제하지 않고 다른 이용자에게 보이는 범위를 제한하는 기능입니다.
  • 회원 탈퇴 시 계정 및 관련 데이터는 삭제 절차에 따라 삭제됩니다.
  • 법령상 보관 의무가 있는 정보는 해당 기간 동안 보관 후 삭제될 수 있습니다.

6. 위치정보 처리

  • 다이어리에는 이용자가 지도에서 선택하거나 현재 위치 기반으로 작성한 장소의 좌표, 주소, 장소명이 저장됩니다.
  • 현재 위치는 지도 이동 및 다이어리 작성 편의를 위해 사용되며, 다이어리로 저장하지 않는 한 서버에 저장하지 않습니다.
  • 위치 권한은 기기 설정에서 언제든지 철회할 수 있습니다.

7. 푸시 알림

  • 알림 권한을 허용한 경우 친구 요청, 요청 수락, 다이어리 공유, 추억 스탬프, 과거의 오늘 알림 등을 받을 수 있습니다.
  • 알림 전송을 위해 FCM 토큰, 시간대, UTC 오프셋을 저장할 수 있습니다.
  • 로그아웃, 휴면 신청, 알림 권한 해제 시 알림 토큰은 삭제되거나 더 이상 사용되지 않을 수 있습니다.

8. 개인정보 파기 및 회원 탈퇴

  • 회원 탈퇴는 앱 내 프로필 → 계정 관리 → 회원 탈퇴에서 진행할 수 있습니다.
  • 탈퇴 시 Firebase Authentication 계정, 프로필, 다이어리, 임시저장, 그룹, 친구 관계, 공유 데이터, 미디어 파일 등 관련 데이터가 삭제됩니다.
  • 삭제된 데이터는 복구할 수 없습니다.

Pinvely ("the Service") is a mobile app that helps users record everyday moments on a map and selectively share diaries with friends. This Privacy Policy explains what information we collect and how we use it.

1. Information We Collect

Account and profile
  • Firebase user identifier (UID)
  • Email address provided through Google Sign-In or Apple Sign In
  • Nickname, profile photo, and profile color
  • Friend code and normalized friend code for friend search
  • App preferences such as language, theme, and color tone
Diaries and sharing
  • Diary title, content, date, place name, address, and map coordinates
  • Topic icon, mood, weather, and diary group information
  • Attached photos and videos, and draft data
  • Friends or friend groups selected for sharing, and shared diary metadata
  • Memory stamps, read status, and related shared diary activity
Friends and notifications
  • Friend requests, friend relationships, friend groups, and friend display colors
  • FCM token for push notifications
  • Timezone and UTC offset for notification timing
  • Dormant account status and dormancy request time

2. How We Use Information

  • To authenticate users and provide profile features
  • To create, view, edit, delete, and save map-based diaries and drafts
  • To provide friend codes, friend requests, friend groups, and shared diary features
  • To provide read status and memory stamps for shared diaries
  • To provide search, filters, total diaries, shared diaries, and memory timeline features
  • To send push notifications for friend requests, accepted requests, shared diaries, memory stamps, and On This Day reminders
  • To maintain user preferences such as theme, language, and color tone
  • To process dormancy, reactivation, logout, and account deletion

3. Sharing and Visibility

  • Diaries are private by default.
  • Only diaries that users choose to share with friends or friend groups are visible to those friends.
  • If a friendship is removed, previously shared diaries are hidden from both sides. If the friendship is restored, prior shared records may become visible again.
  • When an account is set to dormant, friend presence, shared diaries, and memory stamps are hidden from others until reactivation.

4. Retention

  • We retain user information while the user uses the Service.
  • Dormancy hides account-related information from other users but does not delete the data.
  • When a user deletes their account, account-related data is deleted through the deletion process.
  • Information that must be retained by law may be kept for the required period and then deleted.

6. Location Information

  • Diaries store the coordinates, address, and place name selected on the map or used when creating a diary from the current location.
  • Current location is used to move the map and help create a diary, but it is not stored on our servers unless saved as part of a diary.
  • Location permission can be revoked at any time in device settings.

7. Push Notifications

  • If notification permission is enabled, users may receive notifications for friend requests, accepted requests, shared diaries, memory stamps, and On This Day reminders.
  • We may store an FCM token, timezone, and UTC offset to send and schedule notifications.
  • When a user signs out, becomes dormant, or disables notification permissions, notification tokens may be deleted or no longer used.

8. Data Deletion and Account Deletion

  • Users can delete their account in Profile → Account Management → Delete Account.
  • Account deletion removes the Firebase Authentication account, profile, diaries, drafts, groups, friend relationships, shared data, media files, and related account data.
  • Deleted data cannot be recovered.

9. User Rights

  • Request access, correction, or deletion of personal information
  • Request restriction of processing
  • Request dormancy or reactivate a dormant account
  • Delete an account and request data deletion

10. Children's Privacy

The Service is not intended for children under the age of 14, and we do not knowingly collect personal information from children.
